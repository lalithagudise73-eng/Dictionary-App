# 📖 Dictionary App

## Introduction

The Dictionary App is a web-based application developed
using HTML, CSS and JavaScript.

The application allows users to search for words and view
their meanings, parts of speech, synonyms, antonyms and
example sentences.

## Objectives

- Search for words.
- Display word meanings.
- Display parts of speech.
- Display synonyms.
- Display antonyms.
- Display example sentences.
- Demonstrate JSON data processing.
- Implement testing and simulation.

## How to Run

1. Open the project folder in VS Code.
2. Open the project using a local development server.
3. Open index.html in the browser.
4. Enter a word in the search box.
5. Click Search.
6. The application displays the word information.

Example:

Input:
happy

Output:

Meaning:
Feeling or showing pleasure and contentment.

Part of Speech:
Adjective

Synonyms:
joyful, cheerful, pleased

Antonyms:
sad, unhappy
